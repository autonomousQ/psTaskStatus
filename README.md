Windows Task Scheduler monitor with console and HTML dashboard interfaces

Monitor all scheduled tasks with a `_` prefix — see which ones passed, failed, are running, or were never executed, at a glance.
---

## Features

- Discovers all non-disabled scheduled tasks whose names begin with `_`
- Maps Windows Task Scheduler result codes to human-readable status labels
- Console interface — formatted table output directly in the terminal
- HTML dashboard — self-contained `index.html` with summary cards and a data table
- Color-coded status indicators: green for success, blue for running, red for failure
- Animated pulsing dots for active (running) and failed tasks in the HTML view
- Summary cards showing total, passing, failing, and running task counts
- Auto-refreshes the HTML page every 5 minutes
- Manual refresh button with loading spinner
- Dark theme UI (GitHub-inspired) using IBM Plex Mono/Sans fonts

---

## Files

| File | Description |
|------|-------------|
| `psTaskStatus.ps1` | Console script — queries tasks and prints a formatted table, then waits 5 s |
| `psTaskStatus.cmd` | Batch launcher — runs `psTaskStatus.ps1` via `powershell -NoProfile -ExecutionPolicy Bypass` |
| `psTaskStatus-ui.ps1` | HTML dashboard generator — queries tasks and writes `.\index.html` |

---

## Requirements

- Windows (uses `Get-ScheduledTask` / `Get-ScheduledTaskInfo` cmdlets)
- PowerShell 3.0 or later (included with Windows 8 / Server 2012 and newer)
- Administrator privileges to query the Task Scheduler service

---

## Usage

### Console view

Double-click `psTaskStatus.cmd`, or run from a command prompt:

```cmd
psTaskStatus.cmd
```

Or call PowerShell directly:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "psTaskStatus.ps1"
```

The script prints a table and pauses for 5 seconds before exiting.

### HTML dashboard

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "psTaskStatus-ui.ps1"
```

Open the generated `index.html` in any browser. The page auto-refreshes every 5 minutes and also prints a summary to the console at generation time.

### Scheduling

Either script can be added to Windows Task Scheduler to run automatically (e.g. every 5 minutes). The `_` prefix convention means these monitoring tasks will not appear in their own output.

## Status Codes

| Result code | Label | Indicator |
|-------------|-------|-----------|
| `0x0` | Success | Green |
| `0x41301` | Currently Running | Blue (HTML) / Yellow (console) |
| `0x41303` | Task Not Yet Run | Neutral |
| `0x800710E0` | Terminated By User | Neutral |
| `-1` | Error (query failed) | Red |
| *(anything else)* | Unknown `0x…` | Red |

## Dashboard

The HTML dashboard generated by `psTaskStatus-ui.ps1` includes:

- **Header** with title and last-updated timestamp
- **Summary cards** — Total Tasks / Passing / Failing / Running
- **Task table** — Task Name, State, Next Run, Last Run, Result, Missed Runs
- **Animated dots** — pulsing red for failed tasks, pulsing blue for running tasks
- **Footer** noting the 5-minute auto-refresh cycle and data source
